Dig It 帮助与支持

这份指南帮助你开始提取关键帧、选择模式、导出选中画面，并了解本地处理方式。

App Store

快速开始

  1. 从文件或照片导入视频。
  2. 选择均衡、封面或步骤模式。
  3. 查看提取出的画面，并选择值得保留的关键帧。
  4. 导出选中的 PNG 图片，或把项目保存到历史记录。

如何选择提取模式

  • 均衡：适合多数视频的中等数量干净结果。
  • 封面：更少但更强的封面、缩略图和主视觉候选。
  • 步骤：保留更多变化点，适合教程、流程和操作内容。

Mac 命令行工具

高级用户可以在终端或自动化工具中使用 digit CLI，从本地视频提取关键帧、联系表、采样帧和 JSON 元数据。请从 GitHub 项目源码构建 CLI。

digit extract video.mp4 --output ./frames --mode balanced --json frames.jsondigit contact-sheet video.mp4 --output sheet.png --columns 4digit sample video.mp4 --output ./samples --every 10 --max 30digit preset-template --output workflow.jsondigit extract video.mp4 --output ./frames --preset workflow.json

常见问题

Dig It 会上传视频吗？

不会。Dig It 会在设备本地处理视频，除非你主动导出或分享文件。

为什么需要照片权限？

只用于选择源视频/图片，以及在你要求时保存导出结果。

可以重新打开旧项目吗？

有轻量预览的已保存项目可以重新打开；仅保存元数据的记录只能查看信息。
