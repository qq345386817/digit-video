Extraire des images vidéo par lots sur Mac

Ajoutez des vidéos ou un dossier, choisissez un préréglage, puis examinez chaque résultat ou exportez des PNG/JPEG automatiquement. Le traitement reste sur votre Mac.

App StoreAide

Mis à jour: 2026-10-11

Premiers pas

  1. Ajoutez des vidéos ou sélectionnez un dossier dans l'espace Mac. Les vidéos compatibles des sous-dossiers sont aussi incluses : préparez un dossier contenant les clips utiles.
  2. Choisissez un préréglage de révision équilibrée, couvertures ou étapes de tutoriel avant d'ajouter les vidéos. Chaque tâche conserve le réglage choisi à l'ajout ; les modifications suivantes concernent les nouvelles tâches.
  3. Pour l'export automatique, choisissez le dossier de sortie, le format, le modèle de noms et la gestion des fichiers existants. Renommer conserve les exports précédents ; utilisez Écraser uniquement dans un dossier dédié.
  4. Examinez les résultats terminés, sélectionnez les images utiles et exportez-les. La pause après la tâche actuelle attend la fin de la vidéo en cours ; Reprendre traite les tâches restantes.

Le contenu de vos exports par lots

L'export automatique crée un dossier par vidéo. Les noms peuvent inclure le nom de la vidéo, le numéro de l'image et l'horodatage. Les métadonnées JSON facultatives enregistrent noms de fichiers, temps et scores ; les planches-contact donnent une vue d'ensemble. Le format du préréglage s'applique à l'export automatique, alors que la page des résultats exporte les images sélectionnées en PNG.

Examinez une sélection de moments utiles

Les modes sélectionnent des moments représentatifs plutôt que toutes les images. Couverture privilégie une petite sélection ; Étapes conserve davantage de changements pour les tutoriels. Vérifiez les images avant de les utiliser pour un produit ou un document. Sur Mac, choisissez un résultat et parcourez les images sources voisines pour un remplacement plus précis.

Quelles différences entre Mac, iPhone et iPad ?

Mac

Mac ajoute une file de lots, l'import de dossiers, des préréglages, l'export automatique PNG/JPEG et la révision des images sources voisines. Choisissez un dossier de sortie avant d'activer l'export automatique.

iPhone / iPad

Sur iPhone et iPad, choisissez une vidéo dans Photos ou Fichiers, examinez les images, exportez les PNG sélectionnés ou une planche-contact et enregistrez les résultats dans l'historique.

Enregistrez un ensemble d'images à rééditer

Enregistrer conserve les images actuelles ainsi que les horodatages et scores disponibles dans l'historique local. Rouvrez un projet pour examiner, supprimer, exporter et enregistrer les changements dans la même entrée. La vidéo source n'est pas conservée ; les anciennes entrées contenant uniquement des métadonnées ne peuvent pas recréer les images manquantes.
