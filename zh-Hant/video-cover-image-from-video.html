從影片建立封面圖

依需求選擇均衡、封面或步驟模式。

如何選擇擷取模式

均衡：適合多數影片的中等數量乾淨結果。 封面：更少但更強的封面、縮圖和主視覺候選。 步驟：保留更多變化點，適合教學、流程和操作內容。

支援

選取一張擷取結果，使用「匯出封面」調整裁切位置，選擇 PNG 或 JPEG，也可將 JPEG 限制在 2 MB 內。為商品展示、簡報或貼文挑選縮圖，無須上傳影片。

把影片畫面，用在你的作品中

從商品影片挑選展示圖，把教學步驟放進筆記，或為簡報、參考圖板收集靜態畫面。先檢視擷取結果，移除多餘圖片，再匯出需要的部分。縮圖總覽只提供畫面概覽，不會自動撰寫教學，也不是可編輯的影片時間軸。

匯出封面圖片與可列印的 PDF 縮圖總覽

在 Mac、iPhone 或 iPad 上，選取一張結果，使用「匯出 → 匯出封面」。支援原始比例、16:9、9:16、1:1、4:3，可調整裁切位置和最大邊長，並儲存為 PNG 或 JPEG。JPEG 可限制為 2 MB，無法符合限制時請選擇較小的尺寸。圖片不會被放大。製作可列印的 PDF 縮圖總覽時，使用「匯出 → PDF 聯絡表」，選擇 A4 或 Letter 和 2–4 欄。最多 120 張所選圖片按時間排列、自動分頁，並附有影片名稱和時間戳記。未選取圖片時使用全部剩餘結果；PNG 縮圖總覽圖仍最多包含 40 個影格。

圖片和畫面總覽分別支援哪些匯出格式？

所選靜態圖會匯出為多個獨立 PNG 檔。「匯出封面」可將單張畫面裁切為 PNG 或 JPEG，JPEG 可選 2 MB 容量限制。PNG 縮圖總覽圖最多 40 個影格；A4 或 Letter 的 PDF 縮圖總覽最多 120 個影格，附時間戳記並自動分頁。Mac 批次自動匯出另支援 PNG/JPEG 圖片與可選 JSON 中繼資料。匯出不會自動儲存歷史紀錄，請主動按下「儲存」。
