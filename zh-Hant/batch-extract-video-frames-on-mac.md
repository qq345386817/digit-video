# 在 Mac 上批次擷取影片圖片

加入多個影片或整個資料夾，選好擷取預設，再逐一查看結果或自動匯出 PNG/JPEG 圖片。處理在 Mac 本機完成。

[App Store](https://apps.apple.com/app/id6508171056)

[幫助](https://digit-video.luopeike.com/zh-Hant/help)

更新日期: 2026-11-11

## 快速開始

1. 在 Mac 批次工作區加入影片或選擇資料夾。子資料夾中的支援影片也會加入，建議先準備只包含目標素材的資料夾。

2. 加入影片前選擇均衡檢視、封面組合或教學步驟預設。每個工作保留加入佇列時的預設，之後的調整只影響新加入的工作。

3. 自動匯出前先選擇輸出資料夾，再設定圖片格式、命名範本和同名檔案處理方式。重新命名可保留之前的匯出；覆寫僅適合專用匯出目錄。

4. 完成後查看結果，選取有用的畫面並匯出。「目前完成後暫停」會等目前影片處理完再暫停佇列，「繼續」會處理剩餘工作。

## 批次匯出會產生什麼？

自動匯出會為每個影片建立目錄。命名範本可包含影片名稱、影格序號和時間戳記。可選的 JSON 中繼資料記錄圖片檔名、時間戳記與評分，聯絡表提供畫面總覽。預設格式用於自動匯出，結果頁的「匯出所選」則產生 PNG。

## 檢視更精簡的關鍵時刻

擷取模式挑選代表性畫面，並非匯出影片的每個影格。封面模式偏重少量封面候選，步驟模式保留更多教學變化點。用於商品頁或文件前，請先查看結果。Mac 上需要精確替換時，選取一張結果，以來源影片附近的逐格控制調整。

## 在 Mac 上按間隔或時間點擷取影片圖片

取樣影格、來源尺寸匯出、封面裁切和 PDF 縮圖總覽需要 Dig It 1.4.3 或更新版本。取樣與來源尺寸匯出僅限 Mac；封面和 PDF 總覽支援 Mac、iPhone 與 iPad。

在 Mac 工作區加入影片前，先選擇「影格選擇」：自動關鍵影格、固定間隔、指定時間點或均勻取樣，並設定 1–120 個影格的上限。固定間隔達到上限後停止；均勻取樣涵蓋完整時間軸。時間點支援秒數或 HH:MM:SS，例如 5, 00:12.5, 01:30。自動匯出時可開啟「來源影片解析度」，或在結果頁選取圖片，使用「匯出 → 匯出原畫 → PNG/JPEG」。原畫逐格解碼並儲存，不會放大圖片；4K 輸出需要 4K 來源影片。原畫匯出需要目前工作區中的來源影片仍可使用。

## 匯出封面圖片與可列印的 PDF 縮圖總覽

在 Mac、iPhone 或 iPad 上，選取一張結果，使用「匯出 → 匯出封面」。支援原始比例、16:9、9:16、1:1、4:3，可調整裁切位置和最大邊長，並儲存為 PNG 或 JPEG。JPEG 可限制為 2 MB，無法符合限制時請選擇較小的尺寸。圖片不會被放大。製作可列印的 PDF 縮圖總覽時，使用「匯出 → PDF 聯絡表」，選擇 A4 或 Letter 和 2–4 欄。最多 120 張所選圖片按時間排列、自動分頁，並附有影片名稱和時間戳記。未選取圖片時使用全部剩餘結果；PNG 縮圖總覽圖仍最多包含 40 個影格。

## Mac、iPhone 和 iPad 有什麼不同？

### Mac

Mac 提供批次佇列、資料夾匯入、擷取預設、自動 PNG/JPEG 匯出和來源影片附近的逐格檢視。啟用自動匯出前須選擇輸出資料夾。

### iPhone / iPad

在 iPhone 和 iPad，從照片或檔案選擇單一影片，檢視、篩選並匯出所選 PNG 圖片；可將單張封面裁切為 PNG/JPEG，或製作 PNG 與 PDF 縮圖總覽。按下「儲存」才會將完整結果集保留至歷史紀錄。

## 儲存之後還能繼續編輯的結果集

按下「儲存」，才會將目前完整結果集及可用的時間戳記存入本機歷史紀錄。重新開啟後可查看、刪除、匯出，再覆寫儲存至同一筆紀錄。歷史紀錄不儲存來源影片；較舊的僅中繼資料紀錄無法重建遺失的圖片。
