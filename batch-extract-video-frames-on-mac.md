# Batch extract video frames on Mac

Queue video files or a folder, choose a reusable extraction preset, and review each result or export PNG/JPEG images automatically. Processing stays on your Mac.

[App Store](https://apps.apple.com/app/id6508171056)

[Help](https://digit-video.luopeike.com/help)

Updated: 2026-10-11

## Getting started

1. Add video files or choose a folder in the Mac batch workspace. Supported video files in subfolders are included, so start with a folder containing only the clips you need.

2. Choose Balanced Review, Cover Pack or Tutorial Steps before adding the videos. Each queued job keeps the preset selected when it was added; changing the controls applies to new jobs.

3. For automatic export, choose an output folder and set the image format, naming template and file-conflict behavior. Use Rename to preserve earlier exports; use Overwrite only in a dedicated export directory.

4. Review the completed frame set, select useful stills and export them. Pause After Current pauses the queue after the current video finishes; Resume continues the remaining jobs.

## What your batch exports contain

Automatic export creates a directory for each video. Naming templates can include the video name, frame index and timestamp. Optional JSON metadata records image filenames, timestamps and scores; contact sheets provide a visual overview. The preset's image format applies to automatic export, while the result page exports selected images as PNG.

## Review a smaller set of useful moments

Extraction modes select representative moments rather than exporting every video frame. Cover favors a smaller cover-image set; Steps retains more changes for tutorials. Review the images before using them in listings or documentation. For a precise replacement on Mac, select one result and use the nearby source-frame controls.

## What is different on Mac, iPhone and iPad?

### Mac

Mac adds a batch queue, folder import, extraction presets, automatic PNG/JPEG export and nearby source-frame review. Choose an output folder before enabling automatic export.

### iPhone / iPad

On iPhone and iPad, choose one video from Photos or Files, review the extracted images, export selected PNGs or a contact sheet, and explicitly save results to History.

## Save a frame set you can return to

Save keeps the current result images and their available timestamps and scores in local History. Reopen a saved project to review, delete, export and save changes to the same record. The source video is not stored with the history record; older metadata-only records cannot recreate missing images.
