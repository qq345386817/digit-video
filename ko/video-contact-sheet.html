동영상 콘택트 시트 만들기

콘택트 시트는 여러 정지 이미지를 하나의 PNG로 모읍니다. 표지를 비교하거나 장면 요약과 튜토리얼 단계를 공유할 때 원본 동영상을 보낼 필요가 없습니다.

App Store도움말

업데이트: 2026-10-11

시작하기

  1. 동영상을 가져오고 모드를 선택한 뒤 전체 결과를 기다리세요. 콘택트 시트는 Mac, iPhone과 iPad에서 사용할 수 있습니다.
  2. 포함할 프레임을 선택하세요. 선택하지 않으면 남아 있는 모든 이미지가 포함되며 프레임을 삭제하면 현재 결과에서 제외됩니다.
  3. 내보내기 메뉴에서 콘택트 시트를 선택하세요. 결과 페이지의 시트에는 프레임 번호와 타임스탬프가 있어 원본의 해당 순간을 찾기 쉽습니다.
  4. 만들어진 PNG를 저장하거나 공유하세요. 선택 항목 내보내기는 개별 PNG 파일을 만드므로 각각 편집해야 할 때 사용하세요.

결과 페이지 시트당 최대 40프레임

결과 페이지에서는 한 시트에 최대 40프레임을 넣을 수 있습니다. 더 많은 이미지는 작은 그룹으로 나누어 여러 번 내보내세요. 시트는 전체 보기용이며 개별 이미지를 대신하지 않습니다. Mac 일괄 프리셋에서도 콘택트 시트 출력을 선택할 수 있습니다.

전체 보기와 개별 이미지를 함께 사용하세요

상품 동영상은 표지 후보를 비교한 뒤 한 장을 내보내세요. 튜토리얼은 협업자에게 시트를 공유한 뒤 필요한 단계 이미지를 개별로 내보내세요. 나중에 같은 결과를 다시 검토하고 편집하려면 프로젝트를 직접 저장해야 합니다. 시트 내보내기만으로는 기록이 저장되지 않습니다.

Mac과 iPhone·iPad의 차이는 무엇인가요?

Mac

Mac에는 일괄 큐, 폴더 가져오기, 추출 프리셋, PNG/JPEG 자동 내보내기와 주변 원본 프레임 검토가 추가됩니다. 자동 내보내기 전에 출력 폴더를 선택하세요.

iPhone / iPad

iPhone·iPad에서는 사진이나 파일에서 하나의 동영상을 선택하고 이미지를 검토한 뒤 PNG 또는 콘택트 시트를 내보내고 결과를 기록에 직접 저장하세요.

다시 편집할 수 있는 프레임 모음 저장

저장하면 현재 결과 이미지와 사용 가능한 시간·점수를 로컬 기록에 보관합니다. 프로젝트를 다시 열어 검토, 삭제, 내보내기를 하고 같은 기록에 변경 사항을 저장할 수 있습니다. 원본 동영상은 저장하지 않으며 메타데이터만 있는 오래된 기록은 사라진 이미지를 다시 만들 수 없습니다.
