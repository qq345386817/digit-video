# Dig It 도움말 및 지원

Dig It의 Mac 일괄 처리, 프레임 검토, 콘택트 시트, 저장 프로젝트와 플랫폼 차이를 알아보세요. CLI 제공 상태와 명령 예제도 확인할 수 있습니다.

[App Store](https://apps.apple.com/app/id6508171056)

## Mac과 iPhone·iPad의 차이는 무엇인가요?

### Mac

Mac에는 일괄 큐, 폴더 가져오기, 추출 프리셋, PNG/JPEG 자동 내보내기와 주변 원본 프레임 검토가 추가됩니다. 자동 내보내기 전에 출력 폴더를 선택하세요.

### iPhone / iPad

iPhone·iPad에서는 사진이나 파일에서 하나의 동영상을 선택하고 이미지를 검토한 뒤 PNG 또는 콘택트 시트를 내보내고 결과를 기록에 직접 저장하세요.

## 시작하기

1. 균형, 커버, 단계를 선택합니다.

2. 파일 또는 사진에서 동영상을 가져옵니다.

3. 추출된 프레임을 검토하고 보관할 항목을 선택합니다.

4. 선택한 PNG를 내보내거나 프로젝트를 기록에 저장합니다.

## 추출 모드 선택

- 균형: 대부분의 동영상에 적합한 중간 크기 세트.

- 커버: 썸네일과 커버를 위한 적고 강한 프레임.

- 단계: 튜토리얼과 워크플로를 위해 변화점을 더 많이 유지.

## 다시 편집할 수 있는 프레임 모음 저장

저장하면 현재 결과 이미지와 사용 가능한 시간·점수를 로컬 기록에 보관합니다. 프로젝트를 다시 열어 검토, 삭제, 내보내기를 하고 같은 기록에 변경 사항을 저장할 수 있습니다. 원본 동영상은 저장하지 않으며 메타데이터만 있는 오래된 기록은 사라진 이미지를 다시 만들 수 없습니다.

## 결과 페이지 시트당 최대 40프레임

결과 페이지에서는 한 시트에 최대 40프레임을 넣을 수 있습니다. 더 많은 이미지는 작은 그룹으로 나누어 여러 번 내보내세요. 시트는 전체 보기용이며 개별 이미지를 대신하지 않습니다. Mac 일괄 프리셋에서도 콘택트 시트 출력을 선택할 수 있습니다.

## 자주 묻는 질문

### Dig It이 동영상을 업로드하나요?

아니요. 분석과 추출은 기기에서 이루어집니다. 내보낸 파일의 공유 여부는 직접 결정하며 로컬 추출에는 인터넷이 필요하지 않습니다.

### FFmpeg가 필요한가요?

아니요. App Store 앱은 Apple의 로컬 동영상 처리 프레임워크를 사용합니다. 그래픽 작업 흐름은 터미널 명령이나 별도 FFmpeg 설치가 필요하지 않습니다.

### Dig It은 무료인가요?

현재 App Store에서 무료입니다. 최신 가격과 기기 호환성은 공식 다운로드 링크에서 확인하세요.

### 기록에 원본 동영상도 저장되나요?

아니요. 직접 저장한 결과 이미지와 메타데이터만 보관합니다. Mac의 원본 프레임 검토에는 현재 작업 공간에 사용 가능한 원본이 필요합니다.

### 모든 이미지가 원본 해상도를 유지하나요?

자동 추출 프레임은 현재 비율을 유지하면서 720 × 720픽셀 이내로 맞춥니다. Mac 원본 프레임 검토로 추가한 이미지는 원본 해상도를 사용합니다. PNG 내보내기로 작은 프레임이 확대되지는 않습니다.

### App Store 다운로드에 CLI가 포함되나요?

아니요. digit CLI는 별도 Mac 도구이며 현재 공개 다운로드가 없습니다. 명령 예제를 쓰기 전에 지원팀에 이용 방법을 문의하세요. MCP 통합은 제공되지 않습니다.

### Why does it ask for Photos access?

Dig It uses Photos access only so you can choose source media and save exported results when you ask it to.

## 선택적 Mac 명령줄 도구

digit CLI는 App Store 앱과 별개이며 아직 공개 배포하지 않습니다. 지원팀에 이용 방법을 문의하세요. 아래 예제는 독립 도구를 이미 설치한 사용자를 위한 것입니다.
[CLI 이용 방법 문의](https://digit-video.luopeike.com/ko/support)

```sh
digit extract video.mp4 --output ./frames --mode balanced --json frames.json
```

```sh
digit contact-sheet video.mp4 --output sheet.png --columns 4 --limit 40
```

```sh
digit sample video.mp4 --output ./samples --every 10 --max 30 --json samples.json
```

```sh
digit preset-template --output workflow.json
```

```sh
digit extract video.mp4 --output ./frames --preset workflow.json
```
