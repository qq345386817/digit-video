작업 방식에 맞게

동영상을 이미지로 바꾸는 로컬 작업 흐름

Dig It: Video Keyframes(DigIt)은 동영상에서 재사용할 정지 이미지를 추출합니다. Mac 작업 공간에서 일괄 처리와 세밀한 검토를 하거나, iPhone·iPad에서 하나의 동영상 이미지를 추출하세요.

01

Mac에서 동영상 프레임 일괄 추출하기

동영상 파일이나 폴더를 추가하고 추출 프리셋을 선택한 뒤 결과를 검토하거나 PNG/JPEG를 자동으로 내보내세요. 처리는 Mac에서 이루어집니다.

02

주변 원본 프레임에서 이미지 선택하기

Mac에서 하나의 결과를 선택하고 가까운 원본 프레임을 살펴본 뒤 이미지를 추가하거나 교체하세요. 현재 작업 공간에서 원본 동영상을 계속 사용할 수 있어야 합니다.

03

동영상 콘택트 시트 만들기

콘택트 시트는 여러 정지 이미지를 하나의 PNG로 모읍니다. 표지를 비교하거나 장면 요약과 튜토리얼 단계를 공유할 때 원본 동영상을 보낼 필요가 없습니다.

동영상 하나, 새로운 시선.

콘택트 시트로 이야기를 한눈에 살펴보세요. 장면을 비교하고 표지를 고르거나 원본 동영상 대신 시각적 요약을 공유할 수 있습니다.

Mac과 iPhone·iPad의 차이는 무엇인가요?

Mac

Mac에는 일괄 큐, 폴더 가져오기, 추출 프리셋, PNG/JPEG 자동 내보내기와 주변 원본 프레임 검토가 추가됩니다. 자동 내보내기 전에 출력 폴더를 선택하세요.

iPhone / iPad

iPhone·iPad에서는 사진이나 파일에서 하나의 동영상을 선택하고 이미지를 검토한 뒤 PNG 또는 콘택트 시트를 내보내고 결과를 기록에 직접 저장하세요.

샘플링 및 내보내기 상세 안내

Mac에서 간격 또는 타임스탬프로 프레임 추출

새 기능은 1.4.3 이상에서 사용할 수 있습니다. App Store에 업데이트가 아직 없더라도 기존 내보내기 기능을 사용할 수 있습니다.

Mac 작업 공간에 동영상을 추가하기 전에 프레임 선택에서 자동 키프레임, 고정 간격, 지정 타임스탬프 또는 균등 샘플링을 선택하고 1–120개 한도를 설정하세요. 고정 간격은 한도에서 멈추고 균등 샘플링은 전체 동영상을 다룹니다. 시간은 초 또는 HH:MM:SS 형식(예: 5, 00:12.5, 01:30)으로 입력합니다. 자동 내보내기에서 원본 해상도를 켜거나 결과를 선택해 내보내기 → 원본 해상도로 내보내기 → PNG/JPEG를 사용하세요. 원본 프레임은 하나씩 디코딩하고 저장하며 확대하지 않습니다. 4K 출력에는 4K 원본이 필요하고 작업 공간의 원본 동영상을 사용할 수 있어야 합니다.

커버 이미지와 인쇄용 PDF 콘택트 시트 내보내기

Mac, iPhone 또는 iPad에서 결과 하나를 선택하고 내보내기 → 커버 내보내기를 사용하세요. 원본 비율, 16:9, 9:16, 1:1 또는 4:3, 자르기 위치, 최대 변 길이를 선택해 PNG/JPEG로 저장합니다. JPEG는 2 MB 이하로 제한할 수 있으며 맞지 않으면 크기를 줄이세요. 이미지는 확대하지 않습니다. PDF 콘택트 시트에서는 A4/Letter와 2–4개 열을 선택합니다. 최대 120개 프레임을 시간순으로 자동 분할하고 동영상 이름과 타임스탬프를 표시합니다. 선택하지 않으면 남은 모든 결과를 사용합니다. PNG 시트는 여전히 최대 40개입니다.

자주 묻는 질문.

Dig It이 동영상을 업로드하나요?

아니요. 분석과 추출은 기기에서 이루어집니다. 내보낸 파일의 공유 여부는 직접 결정하며 로컬 추출에는 인터넷이 필요하지 않습니다.

FFmpeg가 필요한가요?

아니요. App Store 앱은 Apple의 로컬 동영상 처리 프레임워크를 사용합니다. 그래픽 작업 흐름은 터미널 명령이나 별도 FFmpeg 설치가 필요하지 않습니다.

Dig It은 무료인가요?

현재 App Store에서 무료입니다. 최신 가격과 기기 호환성은 공식 다운로드 링크에서 확인하세요.

기록에 원본 동영상도 저장되나요?

아니요. 직접 저장한 결과 이미지와 메타데이터만 보관합니다. Mac의 원본 프레임 검토에는 현재 작업 공간에 사용 가능한 원본이 필요합니다.

모든 이미지가 원본 해상도를 유지하나요?

미리보기는 720 × 720픽셀 이내입니다. Mac의 원본 해상도 내보내기는 원본 동영상을 필요할 때 디코딩해 원래 크기를 유지합니다. Mac 커버는 사용 가능한 원본을 사용하며 없으면 저장 이미지 해상도를 사용합니다. 저해상도 이미지를 확대하지 않습니다.

App Store 다운로드에 CLI가 포함되나요?

아니요. digit CLI는 별도 Mac 도구이며 현재 공개 다운로드가 없습니다. 명령 예제를 쓰기 전에 지원팀에 이용 방법을 문의하세요. MCP 통합은 제공되지 않습니다.

Why does it ask for Photos access?

Dig It uses Photos access only so you can choose source media and save exported results when you ask it to.
