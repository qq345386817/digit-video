동영상에서 PNG 또는 JPEG 표지 만들기

iPhone이나 iPad에서 두 표지 후보를 비교하거나 Mac에서 원본 영상을 한 프레임씩 확인하세요. 한 장을 골라 자른 뒤 PNG 또는 JPEG 표지로 내보내세요.

동영상에서 커버 이미지 만들기

일반 스틸, 썸네일, 튜토리얼 프레임에 맞게 모드를 선택하세요.

추출 모드 선택

균형: 대부분의 동영상에 적합한 중간 크기 세트. 커버: 썸네일과 커버를 위한 적고 강한 프레임. 단계: 튜토리얼과 워크플로를 위해 변화점을 더 많이 유지.

지원

비교를 닫고 한 장만 선택하면 잘라서 PNG 또는 JPEG 표지로 내보낼 수 있습니다. PDF 콘택트 시트는 프레임 수와 시간 범위를 먼저 확인하세요. 선택한 프레임을 사용하며, 선택이 없을 때만 남은 결과 전체를 사용합니다(PDF당 최대 120장).

어느 프레임이 표지에 어울릴까요?

iPhone / iPad

영상에서 표지로 쓸 한 장을 고르세요. iPhone이나 iPad에서 프레임을 추출하고 두 장을 선택한 다음 선택 개수 옆의 ‘두 프레임 비교’를 누르세요. 두 이미지와 각각의 타임코드를 밀리초 단위로 볼 수 있습니다.

Mac

원하는 장면이 추출된 두 이미지 사이에 있다면 Mac에서 원본 영상을 열고 ‘정밀 프레임 검토’를 사용하세요. 가변 프레임률 영상에서도 실제 프레임을 앞뒤로 한 장씩 확인해 후보를 추가하거나 선택한 한 장을 교체할 수 있습니다.

작업에 바로 활용할 이미지

상품 동영상에서 소개 이미지를 고르고, 튜토리얼 단계를 노트에 담거나, 발표와 참고 보드에 쓸 정지 화면을 모으세요. 결과를 확인하고 불필요한 이미지를 지운 뒤 선택한 장면을 내보낼 수 있습니다. 콘택트 시트는 시각적 요약이며, 설명을 자동 작성하거나 동영상 타임라인을 편집하는 기능이 아닙니다.

커버 이미지와 인쇄용 PDF 콘택트 시트 내보내기

Mac, iPhone 또는 iPad에서 결과 하나를 선택하고 내보내기 → 커버 내보내기를 사용하세요. 원본 비율, 16:9, 9:16, 1:1 또는 4:3, 자르기 위치, 최대 변 길이를 선택해 PNG/JPEG로 저장합니다. JPEG는 2 MB 이하로 제한할 수 있으며 맞지 않으면 크기를 줄이세요. 이미지는 확대하지 않습니다. PDF 콘택트 시트에서는 A4/Letter와 2–4개 열을 선택합니다. 최대 120개 프레임을 시간순으로 자동 분할하고 동영상 이름과 타임스탬프를 표시합니다. 선택하지 않으면 남은 모든 결과를 사용합니다. PNG 시트는 여전히 최대 40개입니다.

이미지와 요약은 어떤 형식으로 내보낼 수 있나요?

선택한 정지 이미지는 개별 PNG 파일로 내보냅니다. 표지 내보내기는 한 프레임을 PNG 또는 JPEG로 자르며 JPEG 용량을 선택적으로 2 MB로 제한합니다. PNG 콘택트 시트는 최대 40프레임, A4 또는 Letter PDF는 최대 120프레임이며 시간 정보와 자동 페이지 나누기를 제공합니다. Mac 일괄 자동 내보내기는 PNG/JPEG와 선택적 JSON도 지원합니다. 내보내기만으로 기록에 저장되지 않으니 저장 버튼을 사용하세요.

관련 가이드

Mac에서 동영상 프레임 일괄 추출하기

동영상 파일이나 폴더를 추가하고 추출 프리셋을 선택한 뒤 결과를 검토하거나 PNG/JPEG를 자동으로 내보내세요. 처리는 Mac에서 이루어집니다.

가이드 읽기 →동영상 콘택트 시트 만들기

시간 정보와 함께 동영상 이미지를 PNG 요약이나 자동 페이지 나누기 PDF 콘택트 시트로 정리하세요. 원본을 보내지 않고 표지를 비교하거나 장면과 튜토리얼 단계를 공유할 수 있습니다.

가이드 읽기 →동영상을 튜토리얼 단계 이미지로

단계 모드로 튜토리얼이나 화면 녹화의 변화 지점을 추출하세요. 선택한 PNG 이미지를 노트, 문서 또는 발표에 쓰거나 시간 정보가 있는 PDF 콘택트 시트로 전체를 살펴볼 수 있습니다.

가이드 읽기 →선택한 동영상 프레임으로 GIF와 MP4 만들기

추출한 프레임 중 2–60장의 정지 이미지를 선택해 Mac, iPhone, iPad에서 소리 없는 짧은 MP4나 움직이는 GIF를 만드세요.

가이드 읽기 →도움말

두 프레임 비교, Mac에서 가변 프레임률 영상 확인, 편집 취소, 표지·콘택트 시트·GIF·무음 MP4 내보내기 방법을 안내합니다.
